### 踩坑记录（重要）
1. **pnpm 9 不能同时配 onlyBuiltDependencies 和 neverBuiltDependencies**（ERR_PNPM_CONFIG_CONFLICT_BUILT_DEPENDENCIES）。electron 二进制下载靠 pnpm 默认阻止 build scripts 实现。
2. **路径工具盘符重复 bug 出现了两次**（shell-api createPathApi 和 Tauri 桥接层各自实现）：join('C:\\x','y') → 'C:\\C:\\x\\y'。正确做法：识别盘符前缀后把首段 'C:' 从段列表里删掉。core/path-guard 同样修过。
3. **MockProcessApi 竞态**：命令处理器同步推流早于调用方 onStdout 订阅 → 测试拿不到输出。修法：缓冲 stdout/stderr/exit，迟到订阅先回放（onExit 若已结束立即回调）。这个模式对 Tauri/Electron 桥接测试同样必要（fake 里用 setTimeout(0) 延后推流）。
4. **jsdom 无 matchMedia**、**RTL 同步断言会踩 React 18 自动批处理**（微任务后才刷新 DOM）→ 浮层类断言用 waitFor；vitest.setup.ts 需手动 afterEach(cleanup)（globals:false 时 RTL 不自动清理，导致"Found multiple elements"）。
5. **vitest `css:false` 下 `?raw` 导入 CSS 不可靠** → theme.test 改用 readFileSync(process.cwd() 相对路径)。
6. **subagent 429 频率限制**：4 个并行 agent 挂了 2 个（T0-04/T0-06），其中一个失败前已写入半成品文件（不同 API 的组件+测试）。**失败的 subagent 可能留下半成品**，接管时要先盘点已有文件。
7. **沙盒删除被 safe-delete 拦截**（trash 二进制超时，rm/unlink 都失败）→ 用 `fs.renameSync` 移入 `.quarantine/` 隔离，最终报告里提醒主人手动清理。`packages/ui/.quarantine/`、`apps/renderer/.quarantine/`、各 `zz-dbg` 残留。
8. **Vite alias 前缀匹配顺序**：`@ec/ui/tokens.css` 必须放在 `@ec/ui` 之前，否则被前缀替换成 `index.ts/tokens.css`。
9. pnpm -r test 的 vitest 输出经管道 grep 会丢，重定向到文件再 grep。
