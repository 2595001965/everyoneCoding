  （ts-morph / libcst / JavaParser，禁用纯文本替换）→ 同步代码/文档/记忆/逻辑结构 →
  单事务 + rename_event + 独立 commit + 一键撤销。DDL 与跨项目引用默认只提示不自动改。
- 同步更新：功能地图 130→157 条、数据模型加 4 张表（registry_entry/occurrence/rename_event/package_job）、

- 关键设计红线（后续实现别走偏）：重命名必须 AST 作用域感知 + 事务可回滚 + 每次独立 commit；
