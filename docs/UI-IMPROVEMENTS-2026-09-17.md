# 界面与交互改进记录 · 2026-09-17

本轮围绕应用外壳、工作台、通用控件和设计器开展改造，并修复实际检查中发现的交互与加载问题。

## 界面与功能

- 新版欢迎页：突出设计器、模型设置和流水线入口，并明确显示本地数据库的连接状态。
- 导航按创作与资源分组，统一线性图标、间距、焦点和选中态；窄窗口自动收起文字。
- 顶栏提供 Ctrl+K 快速跳转、浅色 / 深色 / 跟随系统主题切换，以及可折叠工作指南。
- 重整项目卡片、最近打开、搜索排序、列表视图与加载状态；筛选无结果可一键清除。
- 归档项目可以直接恢复；删除使用带焦点管理的模态确认，执行中防止重复提交。
- 按页面加载设计器、设置、记忆等模块，主入口 JavaScript 从改造中测得的约 812.16 KB 降至 292.53 KB，减少约 64%；gzip 从 267.51 KB 降至约 93.38 KB。这是打包体积比较，不是启动耗时测量。

## 修复的问题

| 问题 | 修复后的行为 |
| --- | --- |
| 通用控件类名与样式表不一致 | 按钮、复合输入框、选择框、复选框、开关、命令面板、弹窗、表格与分栏使用对应样式 |
| 深色设计器的白色控件背景导致文字不清楚 | 面板按钮使用主题令牌，白色画布保持自身文字颜色，浮动工具栏有独立背景 |
| 旧搜索响应覆盖新查询结果 | 只应用当前请求的结果，切换查询或卸载后忽略过期响应 |
| 最近打开加载失败影响主列表 | 独立加载最近记录，主列表不等待它完成 |
| 单个缩略信息失败中断整批加载 | 缩略图与阶段分别降级，后续项目继续加载；图片损坏显示占位 |
| 项目加载失败被显示为首次使用空态 | 展示明确错误与重新加载入口 |
| 归档页只能再次归档 | 按项目视图提供归档或取消归档 |
| 列表内操作冒泡触发项目打开 | 设置、归档和删除操作不触发行选择 |
| 项目操作失败无反馈、重复点击发出重复请求 | 展示失败原因，按项目锁定执行中的操作 |
| 重开项目设置显示旧数据 | 进入设置重新读取项目，隔离旧表单并处理不存在或加载失败 |
| 新手引导在渲染中发请求，失败后可能无限重试 | 在 effect 中读取并处理取消，失败保留静态引导 |
| 侧栏宽度拖动后未持久化，拖动时卸载遗留监听 | 回传最终宽度、保存设置并清理全局指针事件 |
| 无效本地 UI 配置破坏主题、语言或尺寸 | 仅接受有效设置字段，校验类型和尺寸范围 |
| 系统主题改变后界面不跟随，语言设置不更新导航 | 应用接入主题监听，设置变化更新 UI store |
| 通用设置缺失时遮蔽独立 AI 设置入口 | 保留设置类目，按各模块实际可用性显示内容或引导 |
| AI 设置缺失时进入设置页崩溃 | 在渲染依赖 API 的组件前显示连接引导 |
| 设计器热更新重复注册内置组件导致崩溃 | 内置组件注册可重复调用，保留已有注册项 |
| 从 renderer 目录执行测试时路径重复拼接 | 测试资源路径相对测试文件解析 |
| SVG 图标、动作流问题项和 Git 提交列表产生重复 / 缺失 key 告警 | 所有动态子项使用稳定且唯一的 key，异常重复数据也不会复用错误节点 |
| Tooltip 包裹 Tag 时向函数组件传 ref，触发告警且无法定位 | Tag 使用 `forwardRef` 暴露真实元素，Tooltip 可正确计算位置 |
| Electron 安装包缺少 renderer 与数据库迁移，静态资源使用绝对路径 | 生产准备脚本生成相对资源并收集 renderer、迁移和原生绑定到自包含 staging 目录 |
| Electron 打包扫描 pnpm 工作区软链接并重复重建原生依赖 | 主进程继续由 esbuild 完整打包，electron-builder 只读取 staging，并复用已校验的 Electron ABI 绑定 |

## 验证边界

浏览器走查仍使用 mock 外壳。Electron 已验证未签名 unpacked 应用、真实本地数据库迁移和生产 renderer 加载；NSIS 最终安装器因本机无法从 GitHub 下载 electron-builder 的 `winCodeSign` 工具而未生成。Tauri 缺少本机 Rust 工具链，远程 AI 服务也未接入凭据，因此这两部分未做真实运行验证。设计器已有的画布占位渲染方式保留。
