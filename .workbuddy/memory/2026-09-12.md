### 本次真正踩到的坑（已沉淀进技能 4.6）

1. **Read 工具回显的字节可能与磁盘不一致**。`FileDiff.tsx:153` 实际是 `style={cellStyle(...) }}>`（多一个 `}`），
   Read 显示正常；tsc 报 10 处语法错误且末行 167（文件实为 208 行）时，用 `node -e` 读原始字节才定位到。
   **以后 tsc 与 Read 冲突，一律信 node 读出的字节。**
2. **被 429 限流打断的子代理会写坏文件**（写一半）。这批 git UI 组件里只有 `FileDiff.tsx` 受损，
   重写即可；盘点残留用 `tsc -p apps/renderer` 最快。
3. `useHoverJump` 的 Ctrl 状态**必须用 ref 而不是 state**：`window.dispatchEvent(keydown)` 不在 `act()` 里，
   紧随的 `fireEvent.click` 会读到旧闭包 → 表现「按了 Ctrl 不跳转」。
4. `userEvent.setup()` 会替换 `navigator.clipboard`，断言用的 spy 必须在 setup **之后**再 `Object.defineProperty` 装。
5. 给已带文案的按钮加 `aria-label` 会改可访问名，`getByRole('button',{name})` 字符串是全等匹配 → 找不到。

   **位置漂移（写入前复核文本）＝硬失败**，绝不盲替换；文件不存在＝跳过 + 告警。

### 本轮真正踩到的坑（已同步进技能 4.6）

1. **假端口的 `logic.readDocument` 必须深拷贝**：快照与"活对象"共享引用时，执行器原位改名会连带改掉快照，
   "撤销"变成空操作。凡"快照 + 原位修改"的组合都要先深拷贝。
2. **迁移夹具必须是两个独立 sql 围栏**：前向与回滚塞进同一围栏时，`parseGeneratedMigration` 只取到前向、
   回滚为空 → 预览回滚栏**静默为空**（不报错），极难发现。
3. **`splitStatements` 会剥掉结尾分号**：执行器下发的语句没有 `;`，测试里用带分号的字符串比较会永远不相等
   （表现为"注入的失败没生效"）。
4. **`precise` 断言要用对 matcher**：`@ec/ui` 组件的单元格文案常包在括号里（`（剩余 5 天）`）、
   或把 refPath 与 locator 拼成同一个文本节点（`path · file:line:col`），`getByText('精确串')` 会失配，
   要用正则或 `getAllByText`。
5. **测试里的时间基准要和假端口的固定时钟一致**：假端口用固定 `NOW` 计算 `daysLeft`，测试用 `Date.now()`
   造夹具会算出 0 天（本轮踩到，已导出 `NOW` 供测试复用）。
