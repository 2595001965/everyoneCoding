### 关键坑位（都已写进技能 `everyonecoding-wave-implementation` §4.9）

1. **`e2e/vitest.config.ts` 必须设 `root`**：不设则以仓库根为 root，`include` 扫到全仓 235 个测试文件，
   一次跑出 **555 个 `document is not defined` 假红**。而且**用显式文件路径跑时看不出来**
   （路径过滤掩盖了 root 错误），必须跑一次不带路径过滤的 `pnpm test:e2e` 才能暴露。
   实测修正后：10 文件/39 项，241s 全绿。
2. **vitest 不做类型检查**：39 项全绿的同时 `tsc` 报 20+ 错误（`better-sqlite3`/`fastify` 类型解析不到、
   `new Map([...])` 未标注泛型被推成严格类型、`exactOptionalPropertyTypes` 下 `undefined` 要写 `null`、
   假端口字段名与领域类型不一致）。**e2e 交付前必须单独跑 tsc + eslint。**
3. **`startMockServer` 已读完请求体才调用 `route.handler`**：handler 里再挂 `req.on('end')` 永不触发
   → 响应不返回 → 测试挂到超时（表现为 30s timeout 而非报错）。要用 body 必须走 `route.capture`。
4. **`GitClient.setIdentity` 必须在 `init` 之后**（写 `.git/config`，仓库不存在时静默失败 →
   后续 `commit` 被拒且错误隐晦）。
5. **本机 git 子进程 ≈18s/次**：E2E-07 原版约 20 次调用在 300s 超时下跑不完；
   精简为 13 次调用 + 600s 超时后实测 224s 通过。真实推送用 `git init --bare` 的本地裸仓库作 remote。
